# DOC BRIEF – 문서 요약 서비스 (팀 프로젝트)
- 다양한 문서 포맷을 파싱하여 문단/문장 단위로 구조화하고,
이를 기반으로 요약 요청까지 연결하는 백엔드 중심 문서 처리 프로젝트<br/>

![DocBrief](https://github.com/user-attachments/assets/788766c0-6ca5-4633-8bcc-02ae47329004)

## 💻 1.프로젝트 소개
- 파일 또는 URL 기반 문서를 업로드
- 문서 파싱(TXT, PDF, DOCX) 문단 / 문장 단위로 구조화
- 문서 요약 결과 보관함 저장

## 🕑 2.개발기간
